
# Login Attempt Tracker

## Project Overview
Login Attempt Tracker is a beginner-friendly cybersecurity desktop application developed using Python and Tkinter.

It records simulated successful and failed login attempts and displays them on a simple dashboard.

## Features
- Desktop dashboard
- Successful login counter
- Failed login counter
- Total login attempts counter
- Security alert after three failed attempts
- Login activity history
- Date and time for each attempt
- Clear history option

## Technologies Used
- Python
- Tkinter
- Visual Studio Code

## How to Run the Project
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   python main.py

## How It Works
Users can click the Successful Login or Failed Login buttons to record simulated login attempts.

The dashboard automatically updates the counters and records the date and time of each attempt.

When three failed attempts are recorded, the application displays a security warning.

## Project Purpose
The purpose of this project is to understand basic cybersecurity concepts, login monitoring, failed login detection, and desktop application development.

## Project Limitations
This application uses simulated login attempts. It does not monitor real accounts or authenticate actual users.
